# Teste manual no It Takes Two

Não há compatibilidade comprovada até o usuário realizar e relatar este teste. Não altere arquivos do jogo, DLLs, executáveis ou proteções.

Depois que `joy.cpl` mostrar dois controles e ambos responderem:

1. Feche e abra o It Takes Two com os controles virtuais já ativos.
2. Abra o modo de jogo local.
3. Conecte o celular 1 como Jogador 1.
4. Conecte o celular 2 como Jogador 2.
5. Pressione o botão de entrada em cada celular.
6. Teste movimentação e câmera com Modern Dual-Stick.
7. Teste LT, RT, LB e RB separadamente.
8. Teste desconexão e reconexão de cada celular.

Registre versão do Windows, se os dois jogadores foram reconhecidos e quais comandos falharam. Não presuma suporte a anti-cheat.
