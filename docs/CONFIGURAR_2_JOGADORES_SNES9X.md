# Configurar dois jogadores no Snes9x

1. Inicie o Celular Gamepad no PC.
2. Abra o endereço no primeiro celular, informe o PIN e escolha **Jogador 1**.
3. Repita no segundo celular e escolha **Jogador 2**.
4. No Snes9x, abra `Input > Input Configuration`.
5. Em `Joypad #1`, clique em cada comando e pressione o botão correspondente no primeiro celular.
6. Habilite `Joypad #2`, se necessário, e repita usando exclusivamente o segundo celular.

Mapeie `Up`, `Down`, `Left`, `Right`, `A`, `B`, `X`, `Y`, `L`, `R`, `Start` e `Select`. Para multiplayer, selecione também o modo de dois jogadores dentro do jogo. Se um aparelho ocupar o slot errado, desconecte-o e escolha o jogador manualmente ao reconectar.
